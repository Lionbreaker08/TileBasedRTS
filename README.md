# TileBasedRTS
A prototype of an RTS game centred around using tile-based mechanics. 

## Download and Try Out

Download the latest Windows build here:

[Download TileBasedRTS](https://github.com/Lionbreaker08/TileBasedRTS/releases/latest)

Extract the ZIP file and run TileBasedRTS.exe.
